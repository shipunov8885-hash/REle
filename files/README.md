# Папка `files/`

Сюда положите **два PDF-файла** с указанными ниже именами. HTML-страница ссылается на них по относительным путям — как только файлы окажутся в этой папке, ссылки заработают.

## ⚠️ Важно про переименование

Оригинальный файл инструкции часто называется **`3168-р.pdf`** — с **кириллической** буквой «р». На GitHub Pages с такими именами бывают проблемы (404, битые ссылки при клонировании). Поэтому:

1. Переименуйте `3168-р.pdf` → **`3168-r.pdf`** (латинская `r`).
2. Проверьте, что в HTML стоит `href="files/3168-r.pdf"` — так и есть в этой версии.

Если переименовать не получается — откройте `index.html`, найдите строку:

```html
<a class="doc-link pdf" href="files/3168-r.pdf" target="_blank" rel="noopener">

и замените `files/3168-r.pdf` на фактическое имя файла.

## Как положить файлы на GitHub

**Вариант через веб-интерфейс:**

1. Откройте репозиторий на github.com.
2. Зайдите в папку `files/` (или создайте её: **Add file → Create new file**, имя `files/.keep`, коммит).
3. **Add file → Upload files** → перетащите оба PDF.
4. Commit changes.

**Вариант через git:**

```
cp /путь/к/3168-r.pdf files/
cp /путь/к/0594-2016.pdf files/
git add files/
git commit -m "Add PDFs for landing"
git push
```

## Как проверить

Откройте в браузере:

```
https://USERNAME.github.io/REPO/files/3168-r.pdf
https://USERNAME.github.io/REPO/files/0594-2016.pdf
```

Если открывается PDF — всё хорошо. Если 404 — проверьте:

- файл лежит именно в `files/`,
- имя совпадает по регистру (GitHub различает `R` и `r`),
- Pages пересобрался (1–3 минуты после пуша).
